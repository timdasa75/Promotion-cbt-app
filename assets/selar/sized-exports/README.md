# Selar Sized Exports

These are size-specific exports for the Promotion CBT Premium monthly Selar setup.

Selar product image guidance found in Selar Help: use at least 300 x 300 pixels and preferably a square image to avoid cropping. Supported product image formats include PNG, JPG/JPEG, and GIF.

## Recommended Upload

Use **selar-product-image-1000x1000.png** as the main Selar product image. It is square, crisp, and safely above Selar's 300 x 300 minimum.

## Usage Notes

- 300 x 300: minimum compliant fallback / small thumbnail.
- 600 x 600: lightweight product tile.
- 1000 x 1000: recommended product image upload.
- 1200 x 1200: high-quality product image backup.
- JPG versions: use when you want smaller files or if an uploader rejects PNG.
- Wide banners and social squares are optional promo assets, not required for Selar's product image slot.
